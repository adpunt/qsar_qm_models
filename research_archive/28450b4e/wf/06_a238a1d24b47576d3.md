### `auc_norm` formula
```
1791: def _retention_auc_norm(sig, r2, base):
1798:     ret = r2 / base
1799:     srange = sig.max() - sig.min()
1800:     return float(trapezoid(ret, sig) / srange) if srange > 0 else np.nan
```
i.e. AUC_norm = (1/(σ_max−σ_min)) ∫ R²(σ)/R²(0) dσ, trapezoidal, over whatever σ grid the config happens to have (no check that all 11 σ are present — only `len(avg_group) >= 3` at L1823). The docstring's claim "≈[0,1]" is not enforced: `ret` goes negative wherever R²(σ) < 0. Configs with `auc_norm > 1.05` are warned about (L1856) but **kept**; only the *validation* path clips to `[-0.5, 1.1]` → NaN (L1463–1473).

### ANOVA implementations — three different ones

**(1) `run_anova_decomposition` (L1935) — performance, R² at σ=0.3.**

**(3) `_two_way_eta2_unbalanced` (L1394) — validation only.** This one *is* genuinely Type-I sequential, via nested OLS:

## G) WHAT WOULD HAVE TO BE ADDED

### (i) ANOVA on R² at σ = 0.6 under Gaussian noise

**Closest existing function:** `run_anova_decomposition(df, sigma_value=0.3)` (L1935). It is already parameterised on σ; the only reason there is no σ=0.6 result is that `create_figure2` calls it with the default at **L2802** (`perf = run_anova_decomposition(strategy_df)`).

**Minimum change:** loop σ, and restrict to Gaussian.
```
# L2799–2808, inside create_figure2
for strategy in strategies:                      # or just ['legacy']
    for sv in (0.3, 0.6):
        perf_results[(strategy, sv)] = run_anova_decomposition(strategy_df, sigma_value=sv)
```
and widen the `table1_anova_summary.csv` row schema (L2874–2885) with a `Sigma` column.

**Columns needed:** `model`, `rep`, `sigma`, `r2`, `iteration` — **all already present** in `anova_*.csv`. No new experiment required; this is a pure re-run of the existing script on existing ARC data.

**Two defects to fix at the same time, or the σ=0.6 numbers will not be comparable to the σ=0.3 numbers already in the paper:**
1. The σ window is `< 0.05` (L1941), which is fine for a 0.1-spaced grid but should be asserted, not assumed.
2. `run_anova_decomposition` enforces balance by **presence only** (L1957) and computes the residual by **subtraction** (L1992). At σ=0.6 more cells will have dropped iterations (the catastrophic filter, L821, bites harder at high σ), so the design will be more unbalanced and the subtracted residual can go negative — exactly the failure that motivated `_two_way_eta2_unbalanced` (L1394, docstring L1398–1400). The honest fix is to route the performance ANOVA through `_two_way_eta2_unbalanced` as well, or add the `MIN_CELL_ITERS` guard from L2026. Report the per-cell n alongside the η², which neither ANOVA currently emits (only `n` and `n_models`, L1999–2000).

### (ii) An `auc_norm` that is honest about baseline performance at high σ

**Closest existing function:** `_retention_auc_norm` (L1791–1800) and its caller `calculate_robustness` (L1803–1865).

**The dishonesty, precisely.** `ret = r2 / base` (L1798) is a ratio, so a model that falls from R² = 0.95 to R² = 0.30 and a model that falls from R² = 0.40 to R² = 0.13 both score ≈ 0.32 retention at that σ. The trapezoidal mean over σ (L1800) then hides *where* the loss occurred: a model that is flat to σ=0.5 and then collapses scores the same as one that decays linearly. And because `ret` is unbounded below, a config whose R² goes negative at high σ contributes negative area that partially cancels its good low-σ region — the QM9 path does **not** clip (only the validation path does, L1463–1473).

**What to add to `calculate_robustness` (L1842–1849), per (model, rep, strategy) — all from columns already present:**
- `r2_at_sigma` for each σ on the grid (or at minimum `r2_0.3`, `r2_0.6`, `r2_1.0`) — the absolute level the ratio is hiding.
- `auc_raw` = `trapezoid(r2, sig) / srange` — the un-normalised area, so absolute and relative robustness can be reported side by side.
- `sigma_at_r2_half` and `sigma_at_r2_zero` — interpolated σ where R² crosses 0.5·baseline and 0, i.e. a usable-range statistic that is immune to the ratio problem.
- `n_negative_sigma` — count of σ where R²(σ) < 0, so the paper can say which AUC_norm values are contaminated by negative area.
- `ret_min` = `min(r2/base)` — worst-case retention, which the mean hides entirely.
- A per-iteration variant so a **replicate SD on `auc_norm`** exists. Today L1820 averages iterations away before the metric; `run_robustness_anova` (L2071–2082) already builds the per-iteration version and throws it away after the ANOVA. Emitting it as `auc_norm_sd` and `n_iter` costs nothing and is what Table `tab:auc_ranking` needs to justify a 0.005 ranking gap.

**Columns needed:** `sigma`, `r2`, `iteration` — already present. No new data.

### (iii) Direct comparison of the six noise strategies at matched noise dose

**Closest existing function:** `create_methods_figure` (L2529). It is the *only* place in the script that computes anything dose-like — `rmse = np.sqrt(np.mean((y_noisy - y_clean)**2))` at **L2626**, annotated per panel. But it does this on **synthetic Gaussian-mixture data** (L2542–2546) with a **local re-implementation** of the strategies (L2548–2575) at a single hard-coded `sigma = 0.5` (L2578). It touches none of the experimental results, so it cannot support any claim about the real QM9 or ADME runs.

**Nothing in the script compares strategies at matched dose.** Every strategy comparison — `table2_auc_by_strategy_pdv.csv` (L3269), the fig1 heatmaps (L2695, L2758), the fig2 η² bars (L2820), Kendall's W (L3712) — indexes strategies by the *nominal* σ, and nominal σ is not a common dose across strategies.

**What to add.** Two pieces:

1. **A realised-dose table**, per (strategy, σ), from the per-sample uncertainty files. The column `injected_noise` already exists (`scripts/utils.py:238`, and re-derived by `fix_injected_noise`, L980–1021). Group `unc_df` by `['strategy','sigma','rep','model','iteration']` and emit `dose_rms = sqrt(mean(injected_noise**2))`, `dose_iqr`, `dose_p99/dose_p50` (the per-molecule spread — the thing that actually distinguishes outlier/quantile from Gaussian), and `frac_samples_perturbed`. The closest existing machinery is `within_sigma_unc_noise_rho` (L1031), which already slices `model_data` by σ and takes `np.abs(model_data['injected_noise'])` at L1047 — the same access pattern, different reduction.
   - Caveat that must be stated in the output: this dose is measured on the **test** split, and per MEMORY the QM9 test/val noise map is the training map (`rust/src/main.rs`), so QM9 doses read off `injected_noise` are suspect until that is fixed. The KIRBy/validation path is clean.

2. **A dose-indexed robustness curve.** Join the dose table to `qm9_df` on `['strategy','sigma','rep','model','iteration']`, then re-express each strategy's R²(σ) curve as R²(dose_rms) and integrate on a **common dose grid** rather than a common σ grid. That is a new function — call it alongside `calculate_robustness` (L1803) — producing `auc_norm_by_dose` per (model, rep, strategy), interpolated onto the dose range spanned by *all six* strategies. Only then is "outlier noise barely separates the models" (`paper.tex:573`) a statement about noise type rather than about outlier noise delivering, per MEMORY's verified per-strategy RMS at σ=1, roughly half the dose of Gaussian.

**Columns needed:** from the uncertainty files — `strategy`, `sigma`, `rep`, `model`, `iteration`, `sample_idx`, `injected_noise` (all present, `scripts/utils.py:228–238`); from the ANOVA files — `model`, `rep`, `sigma`, `iteration`, `r2` (all present). **No new experiment is required**, but the join key `iteration` must line up between the two file families, which the script never currently checks — `load_anova_data` (L552) and `load_uncertainty_data` (L876) are never joined anywhere in the current 4150 lines.
