# ANSWERS

### 1. Is there ANY local file resolving QM9 to (model × rep × strategy × sigma)?

**No.** Nothing local resolves QM9 to sigma except three narrow exceptions.

The finest general QM9 file is **`results/paper_figures_v2/table2_supp_auc_all_reps.csv`** — 81 rows, `(model × rep)` as the index with the 6 strategies as wide columns, i.e. **(model × rep × strategy), 468 non-blank cells, with sigma already integrated into auc_norm** and the 10 replicates already averaged. `generate_paper_figures_v2.py:3297` builds it with `aggfunc='mean'`.

Three partial exceptions that *do* carry sigma:
- **`results/paper_figures_v2/filtered_catastrophic_iterations.csv`** — 245 rows, `model,rep,strategy,sigma,iteration,r2`. Fully resolved including replicate, but **only the discarded catastrophic runs** (R² < −0.5). It is a defect log, not a result set.
- **`results/mol2vec_investigate_*.csv`** — 30 files, `sigma,iteration,model,rep,sample_size,mae,mse,rmse,r2,pearson_corr,params_source,loss_function`. Fully resolved (11 sigmas × 10 iterations, ~101–110 rows each). But **rep = `mol2vec` only**, models = `dnn` (5 seed variants) and `flexible_dnn{,_64_32,_64_64_32,_128_128,_256_128}`, strategies = **`legacy`, `outlier`, `valprop` only** (3 of 6).
- **`results/calibration_grid/*.csv`** — resolved to sigma × iteration but rep = `continuous_pdv` only, models = conformal wrappers only, **no strategy axis at all**.

### 2. Is there ANY local file with per-replicate values?

**Essentially no — everything usable is already averaged over the 10 replicates.**

The only per-replicate QM9 files are the three listed above (`filtered_catastrophic_iterations.csv`, the 30 `mol2vec_investigate_*.csv`, the 16 `calibration_grid/*.csv`), and none of them covers the main grid. Every table in `paper_figures_v2/` collapses replicates: `table2_supp_auc_all_reps.csv` via `aggfunc='mean'`; `data_inventory.csv` retains only the *count* `n_iterations`; `deep_qm9_*` files retain only `auc_norm_mean`/`auc_norm_std`/`n` where **`n` is the number of reps or models, not replicates**.

Validation data has **no replicate axis at all** — `results/validation_full/**/*.csv` have no `iteration` column (5-fold CV, one value per sigma).

### 3. Is there local QM9 baseline R² (σ=0) per configuration? Verify the deep_baseline_vs_robustness gap claim.

**The gap claim is literally TRUE but practically WRONG — a usable local source exists.**

The claim, verbatim from `results/paper_figures_v2/deep_baseline_vs_robustness.csv:2`:
```
QM9,QM9 (all configs),0,,,,,GAP: QM9 baseline_r2 for baseline-vs-robustness correlation NEEDS server dump qm9_auc_with_baseline.csv (valprop-guarded) OR raw anova_*.csv
```

`n = 0`, all four correlation fields empty. And `deep_gaps.csv:2`: `QM9 baseline_r2 for baseline-vs-robustness correlation,server dump qm9_auc_with_baseline.csv (valprop-guarded) OR raw anova_*.csv`.

Also note `results/paper_figures_v2/excluded_configs.csv` gives `baseline` for the 48 excluded configs, current-vintage.

So: the baseline-vs-robustness correlation **can be computed locally for 454/468 cells** by joining v1 `baseline_r2` onto v2 `auc_norm` — with the caveat that the join is across two pipeline vintages, and the DISCUSSION_TRACKER rule applies before any script change.
