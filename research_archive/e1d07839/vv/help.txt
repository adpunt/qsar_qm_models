Validation Noise Robustness: 3 Regression Datasets with Scaffold CV

options:
  -h, --help            show this help message and exit
  --datasets {logd,caco2,herg_ki,all} [{logd,caco2,herg_ki,all} ...]
                        Which datasets to test (default: all)
  --openadmet-csv OPENADMET_CSV
                        Path to cached OpenADMET CSV
  --results-root RESULTS_ROOT
                        Root directory for results
  --models MODELS [MODELS ...]
                        Only run these models (e.g. --models NGBoost SVM
                        LightGBM)
  --reps {ECFP4,PDV,SNS,MHG-GNN-pretrained} [{ECFP4,PDV,SNS,MHG-GNN-pretrained} ...]
                        Only run these reps (e.g. --reps PDV). Merges with
                        existing results.
  --sigmas SIGMAS [SIGMAS ...]
                        Only run these sigma levels (e.g. --sigmas 0.0 0.5
                        1.0). Default: all 11.
  --gp-kernel {rbf,tanimoto}
                        GP (gauche) kernel. 'rbf' (default) is valid on all
                        reps and matches QM9 gauche_rbf; 'tanimoto' is only
                        valid on binary fingerprints (ECFP4).
  --gp-reps {ECFP4,PDV,SNS,MHG-GNN-pretrained} [{ECFP4,PDV,SNS,MHG-GNN-pretrained} ...]
                        Reps on which to run the GP. Default: PDV only
                        (original behaviour). Pass all four to run GP on every
                        rep so it can enter the cross-rep ANOVA.
  --strategies {legacy,outlier,quantile,hetero,threshold,valprop} [{legacy,outlier,quantile,hetero,threshold,valprop} ...]
                        Only run these noise strategies (default: all six).
                        Splitting a run by strategy is how the uncertainty
                        jobs are spread across the queue -- each job is then
                        ~1/6 the work.
  --unc-strategies {legacy,all}
                        Which noise strategies get their per-molecule
                        uncertainty written to disk. 'legacy' (default)
                        preserves the old Gaussian-only behaviour. 'all'
                        writes all six -- needed to ask whether a model learns
                        WHERE the data is unreliable, since Gaussian corrupts
                        every molecule equally and so has no pattern to learn.
  --threshold-quantile THRESHOLD_QUANTILE
                        Make threshold noise use quantiles of the training
                        labels as its cut-points instead of the absolute
                        +/-1.0 it uses now. On hERG the absolute cut puts
                        EVERY molecule above the threshold, so the arm is a
                        constant and cannot answer the 'where is the noise'
                        question. 0.1 gives the bottom and top tenth. Off by
                        default: turning it on changes the injected noise, so
                        those results are not comparable with runs made
                        without it.
  --no-noise-validation
                        Leave the early-stopping validation labels CLEAN.
                        Default is to corrupt them with the same strategy and
                        level as training: otherwise the neural models are
                        explicitly selected NOT to fit the injected noise,
                        which suppresses the quantity being measured and does
                        so for the neural half of the roster only.
  --oof-outer-folds OOF_OUTER_FOLDS
                        Cross-fit only the first N of the 5 scaffold folds
                        (default: all of them). The 5 folds are trained either
                        way, so TEST-side uncertainty is free for all 5; this
                        only limits the expensive out-of-fold TRAINING pass.
                        --oof-outer-folds 1 cuts the added cost about
                        threefold and still gives every training molecule an
                        out-of-fold score, just without a spread across folds.
  --oof-folds OOF_FOLDS
                        Cross-fit the training set into this many folds and
                        save an out-of-fold uncertainty for every TRAINING
                        molecule (0 = off, the default). Needed to ask whether
                        uncertainty flags the labels that were actually
                        corrupted: scoring a molecule with a model that fitted
                        its corrupted label measures memorisation, not
                        uncertainty. Costs this many extra fits per noise
                        level, and only applies to the models that emit a per-
                        molecule uncertainty.
