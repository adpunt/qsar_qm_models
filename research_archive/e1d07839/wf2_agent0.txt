## 6. Fold / CV construction

- `groups, n_scaffolds = assign_scaffold_groups(smiles)` **L883** → Murcko scaffold string → integer group id (L198–204, `get_scaffold` L186–195).
- `gkf = GroupKFold(n_splits=N_FOLDS)` **L962** — 5 folds, **no shuffle, no random_state** (GroupKFold is deterministic).
- Loop **L966**: `for fold_idx, (train_idx, test_idx) in enumerate(gkf.split(smiles, labels, groups))`.
- Label split L973–974: `y_train_full = labels[train_idx]`, `y_test = labels[test_idx]`.
- **Validation carve, L976–982:**
```python
n_val = len(train_idx) // 5          # 20% of train
val_idx_local = np.arange(n_val)     # FIRST 20% of the fold's train rows, positionally
train_idx_local = np.arange(n_val, len(train_idx))
y_train = y_train_full[train_idx_local]
y_val   = y_train_full[val_idx_local]
```
This is a **positional head-slice, not a random or scaffold-aware split** — `GroupKFold` returns `train_idx` in ascending original-row order, so val = the lowest-index 20% of the training rows and **scaffold groups can straddle the train/val boundary**.
- Feature split L988–992: `X_full = reps[rep_name]`; `X_train_full = X_full[train_idx]`; `X_test = X_full[test_idx]`; `X_train = X_train_full[train_idx_local]`; `X_val = X_train_full[val_idx_local]`.
- `X_val, y_val` are passed only to `run_neural_experiment` (L1017–1019) → `train_neural_regression` (L796–798), used **only for early stopping** (L716–725, patience 10, epochs 100 L798, `criterion(model(X_v), y_v)`).
- **Ordering: validation is carved BEFORE noise injection, and `y_val` is NEVER noised.** Noise is applied inside `run_*_experiment` (L760/L795) to `y_train` only; `y_val` is forwarded unchanged at L797. Early stopping is therefore against clean labels at every σ.
- Tree models get no validation set at all (`run_tree_experiment` has no X_val param, L750).

## Patch hazards (verified, all costly on a cluster)

1. **L1272–1275** — the hERG `run_dataset` call **omits `sigma_levels=sigma_levels`**, unlike logd (L1246) and caco2 (L1262). `--sigmas` is silently ignored for hERG; it falls back to all 11 (L866–867).
2. **L1139–1146** — uncertainty files are overwritten once per fold; only the last fold survives (see §8).
3. **L995 / L1008** — `model_name == 'GP'` breaks under `--gp-kernel tanimoto` (name is `GP-Tanimoto`, L929): no `GP_MAX_N` subsample.
4. **L1044–1046** — bare `except Exception: continue` swallows any per-(model,rep,strategy) failure with only a printed line; missing rows are indistinguishable from unrun ones.
5. **No torch/numpy global seed anywhere** — all 6 neural models are non-deterministic across reruns.
6. **L1030** — uncertainty capture is gated on σ=0.0 being present *and* on `strategy == 'legacy'`; L1039 assumes non-None at every other σ.
7. **L949** gates `MLP` (`mtype == 'mlp-deterministic'`, so `mtype != 'deterministic'` is True) and `VBLL-Full`/`MLP-VBLL-Full` behind `HAS_BAYESIAN_TORCH` even though neither needs torchbnn.
8. **L1189** `--models` has no `choices`; a typo silently produces an empty `experiments` list (L954–957) and an empty result set.
