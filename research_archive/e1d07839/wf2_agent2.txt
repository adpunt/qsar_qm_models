```python
def save_uncertainty_values(y_pred_mean, y_pred_std, y_true_original, y_true_noisy,
                           filepath, model_name, rep, sigma_noise, iteration, file_no,
                           y_pred_std_calibrated=None, temperature=None,
                           epistemic_uncertainty=None, aleatoric_uncertainty=None):
    uncertainty_file = filepath.replace('.csv', '_uncertainty_values.csv')     # :210
    y_orig  = np.asarray(y_true_original, dtype=np.float64)                    # :215
    y_noisy = np.asarray(y_true_noisy,   dtype=np.float64)                     # :216
    finite_mask = np.isfinite(y_orig) & np.isfinite(y_noisy)                   # :217
    if finite_mask.sum() >= 10:                                                # :218
        from scipy.stats import linregress
        slope, intercept, _, _, _ = linregress(y_orig[finite_mask], y_noisy[finite_mask])
        injected_noise = y_noisy - (slope * y_orig + intercept)                # :221
    else:
        injected_noise = y_noisy - y_orig   # fallback                          # :223
    rows = []                                                                   # :225
    for i in range(len(y_pred_mean)):                                           # :226
        row = {'model','representation','sigma','iteration','file_no','sample_idx',
               'y_pred_mean','y_pred_std_uncalibrated','y_true_original','y_true_noisy',
               'injected_noise'}                                                # :227-239
        # :242-247  y_pred_std_calibrated / temperature (else calibrated=uncalibrated, T=1.0)
        # :250-253  epistemic_uncertainty  (else np.nan)
        # :255-258  aleatoric_uncertainty  (else np.nan)
    df = pd.DataFrame(rows)                                                     # :263
    if os.path.exists(uncertainty_file):                                        # :265
        df.to_csv(uncertainty_file, mode='a', header=False, index=False)        # :266
    else:
        df.to_csv(uncertainty_file, mode='w', header=True, index=False)         # :268
```

## 5. Is the noise strategy recorded?

**NO.** Not a column of `save_uncertainty_values` (column list at `scripts/utils.py:229-258` contains `model, representation, sigma, iteration, file_no, sample_idx, ...` and no strategy), and not injected into the filename by `utils.py:210` (the name is purely `args.filepath`).

The strategy survives **only because the caller bakes it into `-f`**: e.g. `slurm_scripts_uncertainty/unc_qrf_outlier.sh:24,26` — `--noise-strategy outlier ... -f ../results/uncertainty_outlier_pdv_qrf.csv`; `unc_dnn_bnn_full_legacy.sh:25,30` — `--noise-strategy legacy ... -f ../results/uncertainty_legacy_pdv_dnn_bnn_full.csv`.

The consumer re-derives it by string-parsing the stem: `scripts/generate_paper_figures_v2.py:904-914` — strips `_uncertainty_values`, requires prefix `uncertainty_` or `anova_`, then matches against `VALID_STRATEGIES = {legacy, outlier, quantile, threshold, hetero, valprop, heteroscedastic, value_proportional}` (`:881-884`) with `STRATEGY_NORMALIZE` (`:885`). It also re-infers the BNN suffix from the filename because the CSV `model` column only says `dnn`/`mlp` (`:919-929`).

Consequence for a patch: **a new output file must keep the `uncertainty_{strategy}_{rep}_{model}` stem convention or the strategy is unrecoverable.**

```python
def decompose_uncertainty_sampling_heteroscedastic(mean_predictions, var_predictions):
    """... mean_predictions/var_predictions: (num_samples, num_datapoints) ..."""
    epistemic = mean_predictions.std(axis=0)
    aleatoric = np.sqrt(var_predictions.mean(axis=0))
    total = np.sqrt(epistemic**2 + aleatoric**2)
    return epistemic, aleatoric, total
```
